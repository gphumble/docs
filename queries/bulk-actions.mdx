---
title: "Act on selected query results"
description: "Select the intended records and apply actions appropriate to contacts or individuals."
---

Run a [query](/queries/build-a-query), review its results, then select the records you want to change. The toolbar shows the selected count.

## Select the intended scope

1. Confirm the result mode: contacts, individuals, or gifts.
2. Select individual rows or use the page-selection control.
3. If you want more than the displayed page, use the offered all-results selection and check the resulting count.
4. Verify a few selected records before opening a bulk action.

Do not assume selecting the page automatically selects all query results. Read the selection count before confirming.

## Available actions

| Result mode | Actions offered |
| --- | --- |
| Contacts | Add Tags, Remove Tags, Add Note, Delete |
| Individuals | Add to Email List, Remove from Email List, Add to Collections, Remove from Collections, Opt In, Opt Out, Delete |
| Gifts | The contact/individual bulk editing and deletion actions are not offered |

Choose the action, complete its dialog, review the scope, and confirm. Check the result or rerun the query afterward: a change can mean a record no longer matches the original conditions.

<Warning>
Delete is irreversible and may be refused for protected records. Read the dialog before proceeding. Updating opt-in status should reflect the person's actual communication choice; list membership alone does not establish consent.
</Warning>

## Troubleshooting

If an expected action is absent, check the result mode. If it is denied, check your permissions. If a large operation reports partial results or errors, review which records changed before repeating it; repeating an Add Note action can create duplicate notes.
