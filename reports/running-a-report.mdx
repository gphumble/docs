title: "Run and filter a report"
description: "Choose a report, set its reporting window, and interpret the refreshed results."
---

Open **Reports** in the sidebar and select a report from the library. You need report-view permission; optional modules control which reports are available.

## Set the scope

1. Open the report and read its description to confirm it answers your question.
2. Select **Window** and choose the reporting period. For a custom window, enter **Start** and **End**.
3. Use **Compare to** when the report supports comparison.
4. Set the available designation, account, tier, frequency, or status filters. Different reports expose different filters.
5. Wait for **Refreshing with new filters…** to finish before interpreting or exporting the result.
6. Review the summary tiles, chart, and detail table together. Read labels and explanatory text for the meaning of each measure.

Filters are reflected in the page address. When sharing a report link with a teammate, they still need their own permission to open it.

## Understand differences between reports

A count of gifts, donors, individuals, memberships, and event tickets measures different things. A household can include multiple individuals and multiple gifts. Choose a report whose unit matches the question.

When comparing totals, use the same window and filters. Check the treatment of refunds and the date shown by the report rather than assuming all totals use identical definitions.

## Troubleshooting

- **No results:** widen the window and remove filters one at a time.
- **Old values while refreshing:** wait for the refresh to complete before exporting.
- **Run failed or network error:** reload and reapply the filters. If it persists, use **Get support** with the report name, filters, and visible error.
- **Missing report:** check module availability and your role.
